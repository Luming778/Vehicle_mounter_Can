# Vehicle Control System - STM32F103 Multi-Node

基于三片STM32F103的车载多节点智能控制系统，支持CAN总线通信、语音控制与WiFi远程控制，具备CAN总线固件升级能力。

---

## 项目简介

本项目采用**分布式三节点架构**，使用三片STM32F103单片机实现车载设备的本地控制、状态显示、语音控制与远程控制。

- **主控屏节点**：负责设备状态显示、语音指令解析、CAN总线通信与WiFi服务器交互
- **设备节点一**：控制车灯、车窗、天窗模块
- **设备节点二**：控制车门模块

三个节点通过CAN总线实现稳定通信，设备状态实时同步至主控屏与服务器，支持本地、语音、远程三种控制方式。

---

## 硬件组成

- 主控芯片：3片 STM32F103 系列单片机
- 通信方式：CAN总线、ESP8266 WiFi模块
- 外设模块：语音识别模块、LCD触摸屏（LVGL图形界面）
- 被控设备：车灯、车门、车窗、天窗
- 外部存储：W25Q32 SPI Flash（固件暂存）、W24C02 EEPROM（升级标志）

## 节点功能说明

### Vehicle_screen_controller（主控屏节点）

1. 通过LVGL图形界面实时显示设备一、设备二的车灯、车门、车窗、天窗状态
2. 支持LCD触摸屏操作控制
3. 接收语音模块指令，解析后通过CAN总线向设备节点下发控制命令
4. 通过WiFi模块将设备状态定时上传至服务器
5. 接收服务器下发的控制指令，通过CAN总线转发至对应设备节点
6. 支持CAN总线固件升级（接收固件写入W25Q32，重启后由bootloader完成升级）

### Vehicle_module_controller_1（设备节点一）

1. 负责控制：车灯、车窗、天窗
2. 本地可通过按键独立控制模块状态
3. 状态变化后通过CAN总线主动上报主控屏
4. 执行主控屏下发的CAN控制指令

### Vehicle_module_controller_2（设备节点二）

1. 负责控制：车门
2. 本地可通过按键独立控制车门状态
3. 状态变化后通过CAN总线主动上报主控屏
4. 执行主控屏下发的CAN控制指令

## 核心功能

1. **LVGL图形界面**
   主控屏通过LVGL驱动LCD触摸屏，提供直观的车载设备状态显示与触摸控制。

2. **设备本地控制**
   设备节点一、二可通过按键独立控制对应模块，状态自动上报主控屏。

3. **语音智能控制**
   语音模块识别控制指令后，由主控屏通过CAN总线向设备节点下发命令，实现语音控制。

4. **WiFi远程控制**
   主控屏通过WiFi模块将设备状态上传至服务器，同时服务器可下发指令，远程控制车载设备状态。

5. **CAN总线通信**
   三个节点通过CAN总线完成状态上报与指令下发，通信稳定可靠，满足车载场景需求。

6. **CAN总线固件升级**
   通过CAN总线将固件传输到目标板，暂存于W25Q32外部Flash，重启后bootloader自动完成升级。详见 [OTA 固件升级系统](OTA/README.md)。

```

├── Vehicle_module_controller_2/    # 设备节点二程序（车门）

    ├── app_update_send/            # OTA发送端固件（烧录器板）
    ├── bootloader_start/           # 目标板启动引导程序（正式版）
    └── Backup programming/         # 目标板备份烧录程序（串口救砖）
```

## CAN总线固件升级系统

本系统支持通过CAN总线更新设备固件，包含三个组件：

| 组件 | 作用 | 说明 |
|------|------|------|
| **app_update_send** | OTA发送端 | 运行在烧录器板，接收PC固件后通过CAN发送给目标板 |
| **bootloader_start** | 启动引导程序 | 目标板上电后检查升级标志，从W25Q32拷贝固件到内部Flash |
| **Backup programming** | 备份烧录程序 | 升级失败时，通过串口直接下载固件救砖 |

### 升级流程

```
PC串口 → app_update_send（烧录器） → CAN总线 → 目标板主程序 → W25Q32暂存
                                                        ↓ 系统复位
                                                bootloader_start → 读取升级标志
                                                        ↓
                                                从W25Q32拷贝到内部Flash
                                                        ↓
                                                    跳转新应用运行
```

### Flash 内存布局

```
0x08000000 ┌───────────────────────────┐
           │  Bootloader (32KB)        │
0x08008000 ├───────────────────────────┤
           │  出厂默认应用 (16KB)       │
0x0800C000 ├───────────────────────────┤
           │  更新后的应用 (464KB)      │
0x08080000 └───────────────────────────┘
```

详细说明请参考 [OTA 固件升级系统文档](OTA/README.md)。

## 使用说明

1. 将三个工程分别下载到对应的STM32F103单片机中
2. 正确连接CAN总线、WiFi模块、语音模块与LCD触摸屏
3. 上电后系统自动初始化并运行
4. 支持本地按键控制、语音指令控制、服务器远程控制、LCD触摸屏控制四种控制方式
